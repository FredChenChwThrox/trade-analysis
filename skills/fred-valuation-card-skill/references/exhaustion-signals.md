# 衰竭信号识别细则

排期卡第 5 步使用。衰竭信号回答的问题不是"到底了吗"，而是"当前位置卖压是否耗尽"。底部是事后确认的，衰竭是当时可观察的。信号的真实胜率约六到七成——它的用法是触发下一档预设计划并配证伪线，不是全仓押注。

## 三种形态（按可靠度排序）

### 形态一：恐慌型衰竭（V 型底标配）

需同时满足：

- 放量：日/周成交量 ≥ 近期均量 2–3 倍；
- 长下影或单日大阳：盘中深坑后收复大部分失地；
- 位置：出现在连续下跌之后，而非下跌初期。

逻辑：放量 + 深坑 + 收复 = 融资盘强平、止损盘集中出清。被迫的卖家卖完就没有第二批——衰竭的本质是被迫卖家的出清。

### 形态二：干涸型衰竭（阴跌末端，左侧交易者的主战场）

满足以下之三中的两个，记一次疑似衰竭：

- 缩量到极致：日成交缩至下跌初期均量的 40–60%；
- 不再创新低：价格横住 ≥3 周，每次下探不破前低；
- K 线实体变小：大跌后出现一连串小阴小阳。

注意：阴跌中的缩量平台可能是下跌中继（休整后再破位）。这正是衰竭信号不单独使用、必须配证伪线的原因。破位时按证伪线止损小额亏损，等下一次信号再执行下一档——靠赔率赢，不靠胜率赢。

### 形态三：背离型衰竭（辅助项）

价格创新低，但周线 RSI / MACD 不创新低（底背离）。单独出现时假信号太多，只作加分项：

- 恐慌/干涸 + 周线背离同时出现 → 该档仓位可按计划上限执行；
- 只有背离 → 不动。

## 打分卡（每周收盘后执行一次，不盯盘）

| 检查项 | 类型 |
|---|---|
| 本周放量（≥2 倍均量）长下影或大阳线 | 恐慌型 |
| 成交量缩至下跌初期均量的 40–60% | 干涸型 |
| 价格 ≥3 周不再创新低 | 干涸型 |
| 周线 RSI / MACD 底背离 | 加分项 |
| 下跌已持续 ≥8 周 | 加分项 |

规则：≥2 项确认才释放排期表上的下一档；不足 2 项时，价格到了也不动。空仓等待是系统的正常状态。反弹不追——追反弹是右侧确认仓的职责，两个模块各管各的扳机。

## 生成排期卡时的具体化要求

把上述通用阈值换算成该股票的实数写进卡里：

- 均量基数：用下跌初期的日均/周均成交量；
- 缩量阈值：基数 × 0.4–0.6；
- 放量阈值：基数 × 2；
- 前低位置：最近一个恐慌低点的具体价格；
- 确认窗口：信号出现后 5–10 个交易日价格是否守住恐慌低点。
