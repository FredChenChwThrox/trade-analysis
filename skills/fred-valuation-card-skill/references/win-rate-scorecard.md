# 胜率打分卡（四源合成）

排期卡第 6 步使用。回答的问题是："这笔买入在约定持有期内盈利的概率有多大"——输出**区间**，不输出点值。胜率与赔率分离管理：赔率由估值锚和情景矩阵给出（第 3、4 步），胜率由本卡给出，两者一起进 Kelly 决定每档仓位上限。衰竭信号只是胜率的四个来源之一，不等于胜率本身。

## 前提：先锁定时间尺度

胜率是持有期的函数。同一笔买入，持有 1 个月和持有 24 个月是两个不同的胜率，不锁定时间尺度，"胜率"这个词没有意义。

- 左侧仓统一按「持有到下一个锚复核周期，约 12–24 个月」估；
- 波段仓按箱体周期（数周到数月）单独估；
- 两个时钟不能混用——不许用长期胜率安慰短期浮亏，也不许用短期波动否定长期假设。

## 四源分解

### 源一：估值位置（权重最大，定基准）

用情景矩阵反推市场定价：现价 ≈ 哪个 EPS 情景 × 哪个 PE 情景，即"市场已经定价了多少坏消息"。

| 现价位置 | 含义 | 基准胜率 |
|---|---|---|
| ≥ 中性EPS × 中性PE | 市场未定价坏消息，不是左侧买点 | 不建左侧仓 |
| ≈ 悲观EPS × 中性PE | 已定价盈利下滑 | 55–60% |
| ≤ 极悲EPS × 悲观PE | 已定价深度恶化 | 60–65% |

胜率问题由此转化为一个可辩论、可证伪的判断：**"现实比市场已定价的情景更差的概率有多大？"** 必须在卡中写明这个判断的依据。

### 源二：盈利轨迹

| 状态 | 加减 |
|---|---|
| 盈利恶化中（最近两季同比加速下滑） | −10% |
| 盈利停滞（增速在零轴附近磨） | 0 |
| 下滑减速 / 改善确认 | +5% ~ +10% |
| 预期裂口未收敛（券商 FY1 预期仍显著高于实际趋势，下修的刀没落地） | −5% ~ −10% |
| 裂口收敛（一致预期已砍到实际趋势附近） | 0 ~ +5% |

证据来源：排期卡第 2 步的盈利底稿，不单独拍脑袋。

### 源三：衰竭信号（时机胜率）

每确认 1 项 +5%，上限 +15%。0 项时价格到了也只允许第一档——第一档是赔率注，胜率天然中等，这是它仓位最小的原因。信号认定标准见 [exhaustion-signals.md](exhaustion-signals.md)。

### 源四：估值体系稳定性与生意质地（以减法为主）

| 状态 | 加减 |
|---|---|
| 估值体系切换中（底部刻度逐轮下移，旧锚失效、新锚样本不足） | −10% |
| 体系稳定（历史底部刻度可复用） | 0 |
| 份额稳定、现金流与净利匹配的龙头 | +5% |
| 毛利率异常下滑 / 费用失控 / 现金流背离净利 | −5% 并触发锚复核 |

体系切换中的股票，源一反推出的胜率要格外警惕：新体系的"底"还在形成中，定价锚本身的置信度就低。

## 合成规则

1. **基准 + 加减，禁止乘法**——四源不独立，相乘会严重低估。
2. **输出区间**：下沿 = 所有扣分项取最大、加分项只算已确认项；上沿 = 扣分取最小、加分算大概率可确认项。
3. **喂 Kelly 一律用下沿**。区间宽度 >15 个百分点说明证据不足，该档按固定比例下限执行，等证据。
4. **每个加减项必须挂证伪点**：写什么 observable 出现就撤销这个加减（如"裂口未收敛 −5%：若下季券商预期下调至实际趋势附近则撤销"）。没有证伪点的加减项不许写进卡。

## 胜率递升与三档结构的关系

三档不是"越跌越买"，是"胜率随证据确认递升，仓位跟胜率走"：

- 第一档：纯估值触发，胜率约 50–55%，赔率最高 → Kelly 小仓；
- 第二、三档：估值 + 衰竭信号 ≥2 项 + 可能的裂口收敛，胜率抬到 60%+ → 加仓。

**关键纪律**：价格下跌但胜率打分没有上升时（信号未出现、裂口未收敛、盈利仍在加速恶化），只允许按固定排期执行，禁止因跌幅大而超配。仓位递增的理由是证据变多了，不是跌幅变大了。

## 生成排期卡时的具体化要求

- 把现价代入矩阵，写明"市场定价组合"（现价 ≈ X EPS × Y PE）；
- 四源各自的加减、证据、证伪点逐条列出；
- 输出三档各自的胜率区间（第一档不含信号加分；第二、三档按信号 ≥2 项已确认计）；
- 各档胜率下沿传给 `scripts/build_schedule.py --winrate` 计算 quarter-Kelly 仓位上限，实际档位比例 = min(固定比例, Kelly 上限)；
- 每季度锚复核时重打一次分：胜率下沿显著上移 → 未买档可提前；显著下移 → 未买档冻结，等下一次打分。
