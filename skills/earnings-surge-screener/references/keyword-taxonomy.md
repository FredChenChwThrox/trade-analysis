# 景气表述关键词体系与检索策略

阶段一（Track A）"双因子筛选"的核心：公司必须在官方披露文本（业绩预告/半年报/招股说明书/调研纪要）中**亲口说出**景气信号，而不是券商或媒体替它说。

## 一、八组强表述关键词（核验用正则见 scripts/verify_announcements.py）

| 组别 | 典型原话 | 信号强度 |
|---|---|---|
| 供不应求 | 供不应求、结构性供不应求、供应短缺、未交订单增多 | ★★★ 最强 |
| 需求旺盛 | 需求旺盛、需求强劲、下游需求持续旺盛 | ★★★ |
| 高景气 | 行业高景气度、景气度上行/回升/提升、景气周期延续 | ★★☆ |
| 供给偏紧 | 供给/供应/供需偏紧、供应缺口、供需格局改善/优化 | ★★★ |
| 价格上涨/中枢 | 价格中枢上移、价格上涨/上行/攀升、提价、量价齐升 | ★★★（周期股关键） |
| 满产/满销 | 满产满销、产能利用率接近满产、排产环比增长、产销两旺 | ★★☆ |
| 超预期 | 超预期（公司自述） | ★★☆ |
| 订单充足 | 在手/手持订单充足、订单饱满/充裕/充沛、订单放量 | ★★☆ |

判定倾向：**"供不应求/供给偏紧/价格上涨"三组权重最高**——它们直接指向"量×价"双击的持续性；"订单充足/满产"是领先指标（当期业绩未必体现，下期兑现）；"高景气/需求旺盛"是标配表述，需结合增速验证。

## 二、公告语义检索的查询模板（gildata_announcement_data）

按关键词组分别发检索（一次查询混多个词会降低召回），查询模板：

```
{报告期}业绩预告或半年报中提到{关键词组}的A股公司公告
```

推荐分组（6-8 次检索可覆盖）：
1. 产品供不应求、需求旺盛
2. 行业高景气度、景气度上行
3. 产品价格上涨、价格中枢上移、提价
4. 供给偏紧、供应紧张、产能不足、满产
5. 新品上市超预期、市场拓展超预期、销量超预期
6. 订单充足、订单饱满、在手订单大幅增长
7. （按热点补）光模块/算力/存储/涨价 等赛道词
8. 招股说明书："{年份}年上市新股招股说明书中提到产品供不应求、行业高景气"

注意：语义检索结果是**模糊命中**，必须用 scripts/verify_announcements.py 对原文做正则二次核验，不可直接用。

## 三、业绩大增判定规则（gate 1）

- 归母净利润同比增速**下限 ≥ 50%**（可用 --min-growth 调整），或**扭亏为盈**且利润体量显著（≥1亿为宜）；
- 剔除：预亏、预降、减亏、续亏；增速贴线（50%~70%）或绝对利润 <1亿的公司**人工复核原文**（脚本可能把订单/营收增速误当利润增速）；
- 警惕**分部扭亏假阳性**：核验"扭亏为盈"命中时确认原话主语是公司整体；若扭亏指向某业务分部（如"XX业务实现扭亏为盈"）而公司整体净利润仍同比下降，剔除（2026-07-30 曾因此误放一家公司入池，人工复核剔除）；
- 警惕**低基数幻觉**：增速 >1000% 时核对上年同期利润绝对额。

## 四、正式财报季与预告季的差异

- 预告季（1月/4月/7月/10月中旬-月底）：以业绩预告为主，文本短、原因直白，是关键词核验的最佳素材；
- 正式报告期：用"半年报/年报 经营情况讨论与分析"章节，关键词同样适用，并增加毛利率、产能利用率、合同负债等量化验证；
- 调研/交流：检索"{公司} 调研 纪要 供不应求/涨价"，用于捕捉管理层口径变化（领先于财报）；管理层信心信号的强弱分级与使用规则（强/中/套话三级、不替代硬信号）**以 `quality-gates.md` 言行合一检验的纪要信心模块为唯一来源**。

## 五、创新药板块景气关键词组（仅医药场景使用，其他行业勿套用）

创新药没有"价格中枢/供不应求"，其"量价双击"由授权出海、获批放量、临床数据构成。检索与核验时替换为以下四组（权重同样按"亲口说出"判定）：

| 组别 | 典型原话 | 信号强度 |
|---|---|---|
| 授权出海 | 对外授权、License-out、首付款、里程碑付款、特许权使用费、与{MNC}签署合作 | ★★★ 最强（直接现金兑现+海外背书） |
| 获批/支付 | 获批上市、纳入医保、商保目录、续约、放量、终端需求持续释放 | ★★★（商业化持续性核心） |
| 临床数据 | 数据读出、ORR/PFS/OS 优效、BIC/FIC、头对头、突破性疗法、快速通道 | ★★☆（管线轨核心，利润轨弱相关） |
| 需求回暖（CXO/产业链） | 研发需求回暖、订单储备充足、业务量与定价同步向好、行业景气度回升 | ★★★（CXO 的"供不应求"等价物） |

查询模板（gildata_announcement_data）：
```
{报告期}业绩预告或半年报中提到对外授权、首付款、里程碑付款的创新药/生物医药公司公告
{报告期}业绩预告或半年报中提到获批上市、纳入医保、销售放量的创新药公司公告
{报告期}业绩预告中提到研发需求回暖、订单充足的CXO公司公告
{报告期}年报/半年报中披露各临床阶段项目数、商业化项目数、新签大额合同的CXO公司公告
```

注：最后一组服务于创新药统一评估框架的CXO服务传导型评估（innovative-drug-framework.md），提取项目漏斗与绑定品种证据。

注意：license-out 驱动的利润大增按 references/innovative-drug-framework.md 第一节混池路由处理——不剥离默认轨道，但必须先按该文件第二节拆分一次性收入并归型，不得仅凭表观增速入核心候选。
