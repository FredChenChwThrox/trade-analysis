# Track C：β错杀轨细则（业绩向好但被市场风格错杀）

## 定位

Track A/B 是顺势轨，赚"景气扩散"的钱；Track C 是逆向轨，赚"定价修复"的钱。目标场景：资金集中追逐高景气主线（如 AI 泛科技）形成吸血效应，非景气行业被无差别抛售，其中**财报业绩真实向好、成长逻辑未破坏**的公司被行业β连累错杀，估值被砸到历史低位——业绩-股价背离即为预期差。

本轨是**错杀成长股轨**，不是格雷厄姆烟蒂轨：目标是"成长性好但被杀估值"（1-2年维度估值修复+成长兑现的双击），不是"盈利稳定的深度低估"（纯股息/清算价值逻辑）。**本文件是 Track C 锚定阈值、四维排雷、催化剂与证据分级的唯一来源。**

## 范围控制原则（与 Track B 同等重要）

**Track C 同样禁止全市场无锚海选。** 但锚不是 Track A 的高景气板块，而是"背离特征"本身——三重锚相乘构成候选池，候选数量控制在 10-30 家。**超出 30 家时按"估值分位升序 → 净利润增速降序"排序取前 30 家；不足 10 家不强行凑数，如实输出并说明当期市场状态。**

### 环境确认闸门（先于三重锚定，决定本轨运行模式）

本轨的全部前提是"结构性吸血"——普涨或普跌环境中，"跌得多+业绩好"更可能是真跌而非错杀。启动锚定前先判市场环境，二选一满足即确认吸血环境：

| 环境信号 | 判定标准 | 查询方式 |
|---|---|---|
| 拥挤度极化 | TMT/AI 板块成交占比处于近一年 70% 以上分位，且非主线行业成交占比持续萎缩 | fin_query / web 搜索查行业成交占比 |
| 相对强弱极化 | 领涨主线指数与候选行业指数 YTD 涨跌幅差 >30pct | fin_query 拉指数区间行情对比 |

- 环境满足 → 正常执行三重锚定，可输出 C1/C2；
- 环境不满足（普涨、普跌、或无明确吸血主线）→ **本轨降级运行：只输出 C3 价值陷阱排除与 C4 下跌合理回避，不推荐 C1/C2**；
- 沪深300 YTD 为负的普跌环境天然不满足（人人皆跌，无背离可言），与 C锚2 的市场状态判定联动。

### 三重锚定（缺一不可）

| 锚 | 判定标准 | 查询方式 | 含义 |
|---|---|---|---|
| C锚1 业绩锚 | 最新财报净利润同比 ≥20%（或扭亏后连续两季改善）；扣非净利润/归母净利润 ≥80%；经营现金流净额为正；**营收同比为正**（通用闸门一，见 quality-gates.md，营收负增长=需求萎缩，与错杀成长定位矛盾） | 选股："筛选最新报告期净利润同比增长超过20%且扣非净利润占比大于80%且经营现金流为正的公司" | 非景气行业难有50%增速，20-30%的稳定增长在深度低估值下已构成双击基础；扣非与现金流是"真业绩"的最低门槛 |
| C锚2 背离锚 | 满足其一：YTD 涨跌幅为负；YTD 跑输沪深300 超 15pct；现价距两年内高点回撤 ≥30%。**背离须按两层行业维度拆解**：个股 vs 所属行业指数（区分个股自身下跌与行业性错杀）、行业指数 vs 沪深300（区分行业被吸血与全市场普跌）——两层皆显著跑输才是"行业β错杀"的完整证据。**先判市场状态：沪深300 同期 YTD 为负的普跌环境中，"YTD 为负"单独不构成背离（人人皆负），须满足跑输或回撤条件之一** | fin_query 拉个股/行业指数/基准三层区间行情 | 股价与业绩的背离是本轨的全部前提 |
| C锚3 估值锚 | PE 或 PB 处于自身近 5 年历史分位 <20%（上市不足 5 年用上市以来区间；数据缺口径时用"当前 PE vs 历史 PE 区间"近似） | fin_query 查估值与历史区间 | **关键闸门**：区分"涨多了的正常回调"（回调后分位仍高，不入选）与"真错杀"（分位<20%） |

**弹性条款**：增速 10-20% 的低速稳定增长蓝筹，若同时满足股息率 >3%、估值分位 <10%、有回购/增持证据，可放宽入池，但默认只进 C2 观察档——增速弹性不足支撑"暴涨"目标，只能按修复逻辑对待。**弹性条款入池者输出时必须声明："按修复逻辑对待，预期形态为估值修复+股息，不是 1-2 年翻倍逻辑"。**

## 四维排雷（错杀 vs 价值陷阱甄别，本轨核心）

跌得多 ≠ 错杀。市场可能先知先觉。四排雷全过才可升级，任一命中即降档或排除：

| 排雷 | 核查项 | 命中即排除/降档的情形 |
|---|---|---|
| 排雷1 业绩质量 | 扣非/归母比例、经营现金流/净利润、应收账款与存货同比异动、商誉占净资产比例、政府补贴与一次性损益占比 | 扣非占比 <80%；经营现金流持续为负或与净利润严重背离；应收/存货增速远超营收；商誉占比 >30% |
| 排雷2 下跌归因分离 | 同行业可比公司是否普跌（行业β）；公司有无个体利空公告（大股东减持、监管处罚、商誉减值、大客户流失、核心产品降价失标） | 下跌主要由公司个体利空驱动而非行业β → 直接归 C4（下跌合理回避），不属于错杀 |
| 排雷3 行业性质 | 行业需求是周期性低迷（库存周期、资本开支周期、政策周期）还是结构性衰退（技术替代、需求永久萎缩） | 结构性衰退行业（如被替代的传统环节）→ C3 价值陷阱；周期性低迷 → 通过，并记录周期位置 |
| 排雷4 持续性 | 次年一致预期净利润方向（沿用阶段二维度2）；市占率与毛利率趋势是否未破坏 | **次年一致预期负增长 → 直接归 C3 价值陷阱（市场可能是对的，便宜有便宜的道理）。这是本轨最重要的安全绳** |

## 修复催化剂清单（与顺势轨最大的不同）

顺势轨等"景气继续验证"，错杀轨等"定价修复触发器"。三层，按信号强度排序：

1. **公司层（最强）**：回购（大额、注销式最佳）、大股东/高管增持、分红率显著提升——低估值下公司自己拿钱投票，是最可信的"市场错了"证据；
2. **行业层**：库存周期拐点（补库启动）、价格战缓和（龙头提价或不再降价）、政策转向（补贴/准入/限产）；
3. **市场层**：拥挤主线（如 AI 板块）拥挤度见顶、资金高低切换、红利/价值风格回归——只作背景佐证，不作为独立入选依据。

催化剂状态直接决定档位：已现 → C1 候选资格；未现 → C2 观察（等右侧）。

## 证据分级

- **★★★**：三锚全中 + 四排雷全过 + 公司层催化剂已现（回购/增持/提分红有公告实证）；
- **★★**：三锚全中 + 四排雷全过 + 催化剂未现或仅行业层信号；
- **★**：锚定有缺口（如弹性条款入池）或排雷存小瑕疵待验证——只进观察名单，写明待验证事项。

## 镜像四档输出

| 档位 | 判定 | 特征 |
|---|---|---|
| C1 核心候选 | 三锚全中 + 排雷全过 + 催化剂已现 | 业绩向好 + 深跌/滞涨 + 估值历史低位 + 公司自证（回购增持） |
| C2 观察 | 三锚全中 + 排雷全过，但催化剂未现 | 一切良好只欠东风，等右侧信号，分批试探可接受 |
| C3 价值陷阱排除 | 排雷1/3/4 任一命中 | **明确输出"不要碰"清单及排除原因——这是本轨最有价值的输出** |
| C4 下跌合理回避 | 排雷2 命中 | 下跌因公司个体恶化，市场定价正确，不属于错杀 |

- 阶段二三维框架的镜像解读（兑现度镜像、持续性沿用、前瞻估值三重锚、机构拥挤度镜像口径、四档口径衔接）**统一以 `forward-framework.md` 第六节为唯一来源**，本文件不重复定义；

- 候选按 `quality-gates.md` 标注增长驱动分型（非经常型原则排除：错杀轨同样不吃"补贴/并表堆出来的增长"）；
- 输出时与 Track A/B 分层并列，标注错杀轨四档（C1-C4）与证据等级（★★★/★★/★），不混排，表内固定含"增长驱动型"列。

## 固有风险与输出纪律（必须声明）

- **信号噪声比天然更差**：顺势轨有"公司亲口说景气"作强验证，错杀轨本质是站在市场定价对立面，胜率更低——排雷纪律宁严勿宽，宁可漏不可错；
- **左侧交易风险显性化**：便宜可以更便宜，风格切换时点不可预测。输出必须绑定分批建仓/右侧确认纪律，并声明这是 1-2 年维度的左侧布局；
- **必须回答"市场为什么错了"**：每个 C1/C2 候选需一句话说明错杀归因（如"行业β拖累+无个体利空+估值分位8%"），回答不了的一律降档；
- **证伪信号差异**：顺势轨证伪=景气证伪（价格下跌、订单取消）；错杀轨证伪=基本面恶化确认（下一期增速转负）+ 催化剂落空（回购终止/规模缩水）+ 行业β继续恶化（拥挤交易未出清、板块资金持续净流出）——证伪信号表按此口径逐候选给出。
