# 三维前瞻分析框架（阶段二：谁是预期差，谁是周期顶）

阶段一（Track A/B）回答"谁业绩好或正在变好"，阶段二回答"谁的股价还没定价这份好、且这份好能持续"。三维相乘，缺一即降级。Track B（早期痕迹层）候选同样过本框架，衔接规则见 `track-b-signals.md` 末节。**候选进入本框架前应先过通用筛选层两道闸门（`quality-gates.md`）；其三个分档维度在本框架中叠加使用：低位程度与维度1数据共用（三选二口径）、机构拥挤度作升降档修正、产业趋势强度并入维度2。本文件是三维评分刻度、四档决策矩阵与镜像解读规则的唯一来源。**

## 一、三个维度（先各评 优/良/中/差）

### 维度1：兑现度（股价已反映多少）
- 拉取**年初至今区间涨跌幅、区间最高价、现价距高点回撤**（gildata_fin_query 区间行情）；
- 评分刻度：**优** = YTD<30% 或下跌/滞涨；**良** = YTD 30-50%；**中** = YTD 50-100%；**差** = YTD>100%（或年内曾涨超 150% 后回落）；
- "曾暴涨 100%+ 后回撤 >50%"型：记"中"并标注**筹码受损**，最高第二梯队（Track C 镜像口径下最高 C2）——涨多了的回调不是预期差；
- **次新股口径**：上市不足 2 年者无 YTD 与两年高点可比口径，改用"较上市首日收盘价涨跌幅 + 较上市以来高点回撤"评估，并标注"次新股口径"。

### 维度2：持续性（明年业绩方向）
- 拉取**券商一致预期净利润：当年与次年**（gildata_fin_query 一致预期）；
- 评分刻度：**优** = 次年一致预期增速 >20% 且行业景气可见度 ≥4 个季度；**良** = 次年增速为正（0-20%）；**中** = 无一致预期覆盖、但行业周期位置支持（Track B 早期痕迹标的主要口径，须写明依据）；**差** = 次年一致预期负增长；
- 维度2 为"差"是第一分水岭：即便当年暴增，也默认归入"周期顶陷阱"（创新药标的须先经拆分归型再定性，见 innovative-drug-framework.md 第一节混池路由）；
- 政策驱动型板块（政策扶持是主要叙事者）必须先过本文件第七节"政策×产能周期矩阵"定位：落在"死亡象限"（政策强 × 产能中期）者，本维度最高记"中"，并写明"产能周期中期，政策扶持正加速产能涌入"原因；
- 用 web 搜索验证行业周期位置：供需缺口持续多久、新产能释放时点、价格斜率变化（涨价减速期利润先于价格见顶）；
- 产业链内部分化：同一涨价周期中，**有定价权的上游/原厂/设计环节**次年继续受益，**赚价差/库存收益的中游（模组、贸易）**次年利润压缩——不要按板块笼统判断。

### 维度3：前瞻估值
- 用一致预期净利润计算/核对次年预测 PE；
- 评分刻度：**优** = 次年 PE<15x 且次年增速 >20%（双击区）；**良** = 次年 PE 15-25x；**中** = 次年 PE 25-40x；**差** = 次年 PE>40x 或当年 PE>60x；次年 PE>50x 者须附"持续超预期"的具体证据方可不记"差"；
- 无一致预期覆盖时用行业可比 PE 估算并标注；周期股不看绝对 PE 低（周期顶 PE 最低），必须结合维度2 的方向。

### 维度4：催化剂日历（排序维度，不作淘汰）

三维定档后回答"什么时候启动"——同样第一梯队，"下季度财报就验证"与"还要等四个季度产能投产"的资金效率完全不同：

- 催化剂类型：财报/业绩预告披露窗口、产能投产时点、新订单/产品放量节点、政策兑现节点、行业价格拐点预期月、公司层事件（回购进展、解禁出清、license-out 签约）；
- 刻度：**优** = 1 个季度内有明确可验证节点；**良** = 2 个季度内；**中** = 3-4 个季度；**差** = 一年内无可跟踪验证点（标注"纯预期，跟踪从简"）；
- 维度4 只决定**同档排序与建仓节奏建议**，不改变档位（档位由前三维决定），数据不足时标"待补充"不评分；
- 与跟踪清单绑定：最近催化剂时点即"下次重检时点"的默认取值。

## 二、输出分层（固定四档，决策矩阵）

先按第一节给三维各评 优/良/中/差，再按下表定档，不凭感觉组合；**同档内按维度4（催化剂日历）距离排序**，最近催化剂近者靠前：

| 档位 | 判定 | 特征 |
|---|---|---|
| S级（超级α核心候选） | 满足第一梯队全部条件，且"S级七项判定清单"七项全中（清单见本节末） | 第一梯队中的第一梯队，同档排序最前；须附言行合一硬信号与产业链卡位的完整证据 |
| 第一梯队（核心候选） | 三维均 ≥良，行业景气可见度 ≥4 个季度，分档维度无硬伤 | 三维全"优"者排序靠前 |
| 第二梯队（观察/已部分兑现） | 任一维为"中"且无"差"；或维度3"差"但维度2"优"（高增长消化估值，须写明超预期假设） | 景气持续、增速为正，但已部分定价 |
| 高危警示（周期顶陷阱） | 维度2 为"差"，不论其他维度 | 当年暴增（常>500%）、次年一致预期负增长；典型：价格周期顶部的中游环节、一次性损益 |
| 已透支回避 | 维度1 为"差"，且维度3 为"中"或"差" | YTD>100%（或年内曾>150%）且估值高企；逻辑正确但股价已定价 2-3 年。维度1"差"但维度3"优/良"的"深涨低估值"者降第二梯队并写明逻辑 |

**分档维度修正（quality-gates.md）**：机构拥挤度 >30%（公募+北向占流通股）或 ≈0 且无券商覆盖者，不得入第一梯队；无法映射已验证产业趋势、或增长驱动分型为周期型/非经常型且无个体订单/份额证据（纯β搭车）者，不得入第一梯队；分型为扩张型且产业趋势明确者，同等条件下优先。

**S级七项判定清单（七项全中方可定 S 级，缺一不可；S 级是分层而非淘汰，未全中但满足第一梯队者维持第一梯队，不因缺项降档）**：

1. **严格双门槛**：营收与净利润增速均 ≥40%（扭亏公司营收 ≥40%；quality-gates.md 闸门一严格模式口径，两条例外通道不适用 S 级——订单驱动型收入未确认者不进 S 级，维持第一梯队跟踪）；
2. **扩张型分型经量化验证**：quality-gates.md 闸门二"扩张/景气分型的量化验证口径"达标（仅文字表述的"分型待验证"者不进 S 级）；
3. **言行合一**：近 6 个月至少命中一条管理层硬信号（quality-gates.md 言行合一检验：增持/回购/高行权条件股权激励/大额扩产/长期锁量协议）；
4. **产业链卡位**：处于链条瓶颈环节（本文件第七节判定 ≥4 项占优）；
5. **政策×产能矩阵落在有利象限**（本文件第七节：政策强×产能早期，或出清转向×产能尾声；政策中性板块此项按"不涉及"记通过，但须在报告中注明）；
6. **机构筹码理想态**：存量 <10% 且增量向上（quality-gates.md 分档维度二组合判定）；
7. **入选前压力测试与证伪清单完备**：入选前先做"拍计算器"三问，至少两问给出定量答案且无硬伤——Q1 供需测算（缺口量级 × 持续季度数 × 公司可得份额增量，能否支撑次年增速假设）；Q2 订单/产能兑现（在手订单 + 合同负债 + 产能爬坡时点，对次年一致预期营收的覆盖率，<70% 且无合理解释 = 硬伤）；Q3 估值消化（现价与透支线之间的剩余空间，与维度3 数据共用）——并给出 ≥3 条可观测、可定量的证伪信号 + 明确复核日历（跟踪重检层直接挂钩）。两条铁律：自称"无法证伪"的叙事型逻辑直接记不通过（无法检验不是逻辑强的证据，是风险本身）；补查细节与主逻辑自相矛盾（如自称供不应求但存货周转显著变差、自称满产但毛利率下滑）即出局。

**创新药例外**：目标为创新药板块时整体改走 innovative-drug-framework.md 统一框架；混合池中个别创新药标的按该文件第一节混池路由处理——license-out 型经拆分归型后方可定性，不得直接贴周期顶标签。

## 三、常见行业周期的"1-2年"判断要点（用搜索更新，勿凭记忆）

- **存储**：原厂供给纪律决定周期长度；模组厂利润=涨价加速度+库存收益，涨价斜率放缓即利润顶（即便价格还在涨）；设计/分销环节滞后于原厂 1-2 个季度见顶；
- **锂电材料（六氟/电解液/隔膜）**：新产能审批+建设周期 12-18 个月是核心变量——当年涨价、次年无有效新产能，则景气可见度覆盖 1-2 年；
- **养殖（白羽鸡等）**：引种/祖代断档 → 商品代的传导周期约 14 个月，价格弹性窗口可精确到季度；
- **船舶/重资产订单型**：看手持订单覆盖年数（≥3 年为强持续）与新接订单价格；
- **石化/炼化**：地缘驱动的涨价持续性弱，次年增速普遍放缓至 10-15%，属"低估修复"非"高成长"；
- **AI 算力（光模块/PCB/服务器）**：跟踪北美 CSP 资本开支指引与技术代际切换（如 800G→1.6T），龙头次年 PE 降到 25x 附近属合理，二线标的预期差更大；
- **有色/贵金属**：股价领先商品价格见顶，宏观（降息/美元）驱动，弹性大但不可按业绩线性外推。
- **创新药/CXO**：创新药板块启用统一评估框架，见 `innovative-drug-framework.md`。要点：价值驱动四分型×统一四维评分卡，盈利兑现型看医保续约价格、单品放量斜率与次年一致预期；license-out 型先拆分一次性首付与主业扣非再归型；管线期权型禁用 PE 语言、看催化剂密度与交易比价锚；CXO 看漏斗迁移、绑定品种与大订单结构（警惕"大单顶"）。

## 四、证伪信号表（输出的必备组成部分）

每个推荐方向必须给出可跟踪的证伪信号，模板：

| 方向 | 核心假设 | 证伪信号（触发即重检） |
|---|---|---|
| 例：电解液 | 六氟价格中枢X万、次年无新增产能 | 价格跌破Y；竞品新产能提前满产；下游排产环比转负 |

证伪信号来源：行业高频价格（SMM/百川/Wind EDB）、公司月度/季度经营数据、券商周报的供需跟踪。**产业趋势级假设（分档维度三）须给出趋势级证伪条件（如政策退坡、渗透率见顶、缺口被新产能填平），与公司级信号分行书写。**证伪信号的跟踪频率与重检动作见 SKILL.md"跟踪重检层"。

## 五、表达纪律

- 明确告知"这是概率判断，非确定性预测"，附"不构成投资建议"；
- 每个数据点标注来源与日期（业绩预告披露日、一致预期日期、行情区间）；
- 区分"公司公告原话"与"券商观点"与"自己的推断"，三者不可混写。

## 六、Track C（β错杀轨）候选的镜像解读

Track C（β错杀轨，锚定与排雷细则见 `track-c-oversold.md`）候选同样过三维框架，但解读规则镜像化。**本节是镜像规则的唯一来源，其他文件不重复定义。**

- **维度1（兑现度）镜像**：顺势轨"YTD高=已兑现=回避"；错杀轨"YTD深跌/大幅回撤 + 业绩向好 = 背离 = 机会候选"。"曾暴涨100%+后回撤>50%筹码受损"规则继续适用：此类标的即便跌得多也只归 C2 观察，不因跌幅升级为 C1——涨多了的回调不是错杀（C锚3 估值分位通常也会将其挡在门外）。
- **维度2（持续性）完全沿用，且地位更高**：次年一致预期方向仍是第一分水岭——为负者在错杀轨直接归 C3 价值陷阱（市场可能是对的，便宜有便宜的道理）。这是错杀轨最重要的安全绳。
- **维度3（前瞻估值）改造**：从"预测PE高低"变为三重锚——历史分位（PE/PB 近 5 年分位 <20%，上市不足 5 年用上市以来区间）+ 绝对水平（次年预测 PE<15x 为佳）+ 股息率（>3% 提供底部支撑，非必需）。**"周期股低PE陷阱"纪律在错杀轨同样生效且更重要**：周期顶 PE 最低，必须结合维度2 方向判断，防止把"周期顶前夜的便宜"当错杀。
- **四档口径**：输出统一按错杀轨四档（C1/C2/C3/C4）呈现——C1/C2 由三锚+排雷+催化剂状态决定（track-c-oversold.md）；维度2"差"者归 C3；排雷2 命中（个体利空）者归 C4。顺势轨的"已透支回避"档在错杀轨不适用（背离锚与估值锚已前置排除），不做机械对应。证据等级（★★★/★★/★）沿用。
- **证伪信号口径**：错杀轨候选的证伪信号表按 track-c-oversold.md 末节口径逐候选给出（基本面恶化确认 + 催化剂落空 + 行业β继续恶化），与顺势轨的景气证伪口径区分，不混写。
- **通用筛选层镜像**：闸门二驱动分型同样适用（非经常型原则排除——错杀轨同样不吃"补贴/并表堆出来的增长"）；机构拥挤度按镜像口径——抛售期机构占比天然偏低，舒适区下限放宽，但"≈0 且无券商覆盖"仍作风险信号写入待验证事项；低位程度维度不重复计算（C锚2背离锚 + C锚3估值锚已覆盖）。

## 七、产业链卡位判定与政策×产能周期矩阵（S级前置验证，兼作维度2与分档维度三的证据加权）

### 卡位判定（"绝对受益"的操作化）

板块景气确认后、个股定档前，判定公司在链条中的瓶颈地位，五项证据：

1. **产能弹性**：该环节产能建设/认证周期 ≥12 个月（弹性低才稀缺，对手无法快速复制供给）；
2. **认证/客户壁垒**：进入头部客户供应链的认证难度与时长；
3. **格局**：CR3 集中度、公司市占率与份额趋势；
4. **可替代性**：有无二供、有无技术替代路线；
5. **议价结构**：应收/应付/预收结构反映的对上下游话语权（预收高、应付账期长=话语权强）。

判定：五项中 **≥4 项占优** → 瓶颈环节，"绝对受益"表述可信（S 级第 4 项通过）；**≤2 项占优** → 价差/库存收益型环节，维持维度2"次年利润压缩"纪律，不得入 S 级；中间态写明"卡位证据待补"。卡位结论必须逐家写明依据，不按板块标签笼统判定——同一板块内卡位差异巨大。

### 政策×产能周期矩阵（政策扶持 ≠ 股东回报）

政策扶持强度与行业资本开支强度正相关："政策扶持 → 资本涌入 → 产能过剩 → 全链条内卷"的螺旋是政策驱动板块的首要陷阱（光伏为典型样本）。两个轴：**政策强度**（扶持力度与政策序列优先级）× **产能周期阶段**（用行业资本开支增速、在建工程、产能利用率定位）。

**政策强度轴的操作化（文件层级 × 资金实证）**：五年规划/中央经济工作会议点名 = 强；部委专项行动方案 = 中；地方文件/协会倡议 = 弱。有国家级产业基金实际投放或财政补贴落地者升一级；仅文件无资金者降一级。政策强度低不单独否决候选，但此时分档维度三不得用政策作为趋势证据（防循环论证）。

| | 产能早期（资本开支刚启动、利用率高位） | 产能中期（资本开支狂飙、在建工程暴增） | 产能晚期/出清后（利用率见底、价格战缓和） |
|---|---|---|---|
| **政策强（第一核心行业）** | 有利象限①：国产替代/技术攻关启动期 → S 级第 5 项通过 | **死亡象限**：政策正加速产能涌入（光伏陷阱）→ 维度2持续性最高记"中"，不得入 S 级 | 有利象限②：政策转向出清（反内卷/供给侧改革）+ 产能尾声 → S 级第 5 项通过 |
| **政策弱/中性** | 中性，看个体α（S 级第 5 项按"不涉及"记通过并注明） | 回避：无政策托底的产能扩张期 | 中性，看周期反转证据 |
