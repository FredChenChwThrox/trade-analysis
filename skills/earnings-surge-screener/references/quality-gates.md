# 通用筛选层：两道闸门与三个分档维度（Track A/B/C 共用）

## 定位

三条轨道（Track A/B/C）解决"谁业绩好 / 在变好 / 被错杀"，本文件解决"业绩是不是真的、增长靠什么、筹码挤不挤、管理层说的是不是真的"。**闸门做淘汰，维度做分档，言行合一做修正**，三者不互相替代：闸门不过的降级或排除，维度不占优的只是不进核心档。**本文件是两道闸门、三个分档维度与言行合一检验数值口径的唯一来源**；创新药板块仅部分参照（适用边界以 innovative-drug-framework.md 第一节为唯一来源），行业闸门规则不变。

## 闸门一：业绩质量（营收印证利润）

利润增速可被低基数、并表、补贴、费用压缩扭曲，营收同步增长是过滤"假性业绩"的第一道闸。分轨口径：

| 轨道 | 利润门槛 | 营收闸门 | 口径说明 |
|---|---|---|---|
| Track A | 净利润增速 ≥50% 或扭亏 | 同期营收增速 ≥30%；扭亏公司同样要求营收 ≥30% | 业绩预告常不披露营收 → 入池后用 `gildata_fin_query` 补查营收增速（每批 ≤3 家，单次最多 3 个明确实体，口径见 SKILL.md「数据源路由」），缺数据者标"待验证" |
| Track B | 单季净利润同比 ≥30% | 同季营收同比为正且与利润方向一致 | 利润增、营收降的单季拐点大概率是成本/基数驱动，证据等级降一级 |
| Track C | 净利润同比 ≥20%（或扭亏后连续两季改善） | 营收同比为正 | 非景气行业不强求 30%，但营收负增长 = 需求在萎缩，与"错杀成长"定位矛盾 |

**分档处理（Track A）**：营收 ≥30% 全过；10%-30% 标"营收偏弱"，进核心档需闸门二为扩张型/景气型且其他维度补强；**营收 <10%（或缺数据且无法补查）→ 标"利润质量待验证"，不进核心档，只进观察档并写明原因**（常见原因：并表、补贴、出售资产、低基数、费用压缩）。

**严格模式（可选收紧，用户要求"双 40%"口径或 S 级判定时启用）**：净利润增速 ≥40% **且**营收增速 ≥40%（扭亏公司按营收 ≥40% 单门槛）。三条例外通道不受收紧影响：①扭亏型（利润无同比增速口径，营收达标即可）；②订单驱动型（收入确认滞后——合同负债/在手订单同比大增但营收暂未达标，如船舶/军工/设备），转 Track B 先行指标口径跟踪，不因营收未达标排除，但须写明"收入未确认"事实；③利润率驱动型（营收 30%-40% 且净利润 ≥40% 且毛利率同比提升 ≥2pct）——可入池参评但标"营收贴线"，不进 S 级、维持第一梯队。

## 闸门二：增长驱动分型（强制标注，决定持续性权重）

筛"业绩为什么增长"比筛"增长多少"更接近未来 1-2 年的持续性。读公告原文"业绩变动原因"段落、业绩说明会与调研纪要，逐候选标注四型之一（输出表一律用汉字标注，不用字母代号）：

| 分型 | 判定 | 处理 |
|---|---|---|
| 扩张型 | 增长主因新产品 / 新服务 / 新客户 / 新市场放量（份额逻辑） | 加分：份额逻辑可穿越单一价格周期，持续性证据权重最高 |
| 景气型 | 量价齐升，公司自身订单 / 产能同步扩张 | 正常参评，阶段二验证行业景气可见度 |
| 周期型 | 增长主因产品价格同比上涨（价格逻辑），无量或份额证据 | **不淘汰**，但阶段二"持续性"维度必须回答周期位置（新产能释放时点、价格斜率），次年一致预期为负即入周期顶陷阱 |
| 非经常型 | 主因低基数 / 并表 / 补贴 / 出售资产 / 会计变更 | 原则排除；扭亏公司首年除外，但须标注 |

**扩张/景气分型的量化验证口径（防"关键词分型"）**：
- 扩张型认定需满足以下之一：最近一期年报/半年报分部（分产品）数据中新品类（新产品/新服务/新市场）收入占比 ≥10%；或新品类收入同比 ≥100% 且被公告"业绩变动原因"段落点名；
- 景气型（量价齐升）认定需以下三项至少两项交叉印证：分产品毛利率同比提升、销量/稼动率数据上行、提价函或锁量涨价类公告；
- 仅有"业绩变动原因"段落文字表述而无数据印证者，标"分型待验证"——进核心档需其他维度补强，且不得作为 S 级证据。

纪律：

- 分型是基于"公告原话 + 纪要"的归因判断，**无法用语义选股硬筛**；归因证据不足时标"未分型"，不猜；
- 周期型不歧视（涨价也是真景气），但必须绑定周期位置判断——这是区分"涨价主升"与"周期顶陷阱"的开关；
- 与既有"供不应求/涨价"关键词体系是**叠加关系而非替代关系**：涨价型公司仍可入选，但分型为周期型即触发阶段二周期位置验证。

## 言行合一检验（管理层表态的信号分级，三轨通用）

管理层的口头表态是廉价信息——调研纪要中"强烈认同"几乎无区分度（全市场绝大多数纪要都乐观），且管理层情绪是同步/滞后指标而非领先指标（历史顶部区域往往是管理层表态最乐观的时点）。信息量在于真金白银的行动。**本检验只修正档位，不做淘汰；Track C 的"回购/增持"催化剂规则与本节一致，此处推广为三轨通用。**

**硬信号（近 6 个月，公告可查证）**：
1. 实控人/董监高净增持（金额与价格锚明确）；
2. 回购（金额、价格上限、已执行进度）；
3. 股权激励/员工持股的行权条件含明确业绩增速门槛（管理层给自己上的对赌）；
4. 大额扩产资本开支（capex 相对在手现金与历史水平显著放大）；
5. 长期锁量/锁价客户协议（绑定真实需求）。

**软信号分级（纪要信心模块，只作辅助，不替代硬信号）**：

公告是法定披露、措辞保守，调研纪要/业绩说明会才是管理层真实信心的流露渠道，也是机构获取预期差的主渠道——但单条乐观表述无区分度，必须按强度分级后使用：

- **检索渠道（按序）**：`gildata_announcement_data` 查"{公司} 投资者关系活动记录表"、"{公司} 业绩说明会"；`gildata_financial_research_report` 查调研类研报中"管理层表示/交流要点"段落（区分券商转述与直接引语，直接引语证据权重更高）；web 搜索补充"{公司} 调研 纪要 {报告期季度}"。公告与纪要口径冲突时以公告为准，并写明冲突点；
- **强信号**：产能利用率/稼动率满产口径；订单能见度明确到具体季度；主动提价；资本开支/扩产计划上调；管理层自述"需求超预期"；
- **中信号**：景气延续、排产环比上行、新客户/新市场导入顺利、库存水位下降；
- **套话（不计入）**："稳步推进""谨慎乐观""积极应对""未来可期"等无信息量表述；
- **使用规则**：强信号 ≥2 个独立场合（公告与纪要互证最佳）→ 记"信心证据充分"，作升档辅助；仅中信号/套话、或无纪要证据 → 中性，写明"管理层信心证据缺位"。软信号再强也不替代硬信号——S 级第 3 项与"不得进核心档"的判定仍以硬信号与背离项为准。

**处理规则**：
- 口头乐观 + 硬信号命中 ≥1 条 → 言行合一，升档加分（与扩张型分型叠加时优先级最高，S 级判定第 3 项以此为据）；
- 口头乐观 + 无硬信号 → 中性，不加分；
- 口头乐观 + 减持/零扩产/行权条件宽松等背离 → 降档，**不得进核心档**；
- 纪要乐观表述只作软信号辅助；输出时必须声明"管理层表态天然乐观"偏差，"公告行动"与"纪要语言"分行书写，不混写。

## 分档维度一：低位程度（三选二，分档依据而非淘汰依据）

满足以下三项中至少两项 → "低位"成立，升档加分；全不满足 → 不是不入选，而是默认归"已部分兑现"，降档处理：

1. YTD 涨幅 <30%，或跑输所属板块指数；
2. 现价距两年内高点回撤 ≥20%；
3. PE 或 PB 处于自身近 5 年历史分位 <50%（上市不足 5 年用上市以来区间）。

口径区分：Track A/B（顺势轨）以**相对涨幅为主、估值分位为辅**——高景气行业估值分位天然偏高，分位 <50% 仅作参考不硬卡，防止把"刚启动但仍有空间的龙头"误杀；Track C 维持 C 锚3（分位 <20%）硬锚不变，本维度不重复计算。"曾暴涨后大幅回撤"型按 forward-framework.md 原规则处理（筹码受损，最高第二梯队）。

## 分档维度二：机构筹码（存量拥挤度 × 增量趋势）

机构资金的判断拆成两层：存量看"挤不挤"（定价是否充分），增量看"进没进场"（后续定价权资金方向）——两层联合使用，增量不豁免拥挤。

**存量拥挤度（不拥挤、不无主）**：

- **舒适区**：公募 + 北向合计持股占流通股比例 3%–20%（fin_query / 选股查机构持股比例）；
- **偏热区**：20%–30%——不降档、不加分，写入待验证事项；若同时股东户数连续上升（筹码分散），按拥挤处理；
- **拥挤**：>30%，或基金重仓占比处于自身历史高分位 → 预期已充分定价 + 调仓踩踏风险，降档，不得进核心档；
- **无主**：机构持股 ≈0 且无券商覆盖 → 流动性与基本面认可度双低，原则不进核心档（Track B 的 ★ 级扩散标的可豁免，但须写明无覆盖事实）。

**增量趋势（资金是否在进场）**——三个观测：

1. 最近两期公募持仓变化方向（季报口径）；
2. 股东户数两期变化（下降=筹码集中）；
3. 研报覆盖密度变化（新增覆盖数，注意区分"刚开始被定价"与"已刷屏"）。

**组合判定**：

- **理想态**：存量 <10% 且增量向上（股东户数连续两期下降 + 机构持股温和上升）→ 加分，S 级判定第 6 项以此为据；
- 存量 >30% 但增量仍在涌入 → 维持拥挤降档不变（增量不豁免拥挤：高位放量进场同样是踩踏预演）；
- 国家产业基金/大基金持仓作为信号记录，**不作"抬轿"逻辑加分**——产业基金投资方向不等于二级市场买点。

**机构审美可及性（前瞻修正项："未来有没有人来买"，与存量/增量分工，不重复计算）**——主升浪需要机构资金接力，本项评估标的是否在机构买盘的可达范围内：

| 检查 | 口径 |
|---|---|
| 市值 | ≥80亿通过；50-80亿标覆盖风险；<50亿记硬伤（须写明） |
| 流动性 | 日均成交额 ≥1亿为宜；<5000万记硬伤 |
| 可研究性 | 已有券商覆盖=中性；细分龙头暂无覆盖=加分（未来覆盖增量——与"无主"风险信号的区别：细分地位明确者可豁免） |
| 可陈述性 | 一句话能讲清"为什么增长、为何持续"；讲不清记不通过 |
| 产业资金可及性 | 处于国家级产业基金投向目录内=加分；目录外=中性，不扣分 |

修正项不做单项淘汰；**两项以上硬伤**（如市值 <50亿 + 无覆盖 + 成交额 <5000万）→ 不得进核心档。

数据局限必须声明：公募持仓按季报披露，**滞后 1-2 个月**，判断用最近两期趋势而非单期快照。

## 分档维度三：产业趋势强度（β保底 ≠ β依赖）

- 每个候选必须能映射到**一条已验证的产业趋势**（政策驱动 / 技术渗透率提升 / 供需缺口），并在证伪信号表中给出该趋势的证伪条件；映射不出明确趋势、仅有个体逻辑的候选，阶段二"持续性"维度证据权重降级；
- **趋势分级（升档依据）**：T1 核心时代趋势（国家级政策文件点名且配套资金；产业资金实际投放 ≥百亿级；渗透率处 5%-30% 加速段且 ≥2 个独立来源验证——三项中至少两项成立）/ T2 一般产业趋势（需求真实、有订单或业绩验证，但非时代主线）/ T3 边缘主题（只有叙事，无订单、无政策资金实证）。T1 且公司为**绝对受益者**（细分市占率前三或唯一/主供地位；可提价或涨价周期中毛利率持平/上行；行业供需缺口的订单首先/主要流向该公司——三项中至少两项）→ 升档优先级最高；T3 或映射不出趋势 → 按上条降级处理；
- 与闸门二配套使用：闸门二管"公司自己有桨"（α），本维度管"行业风在吹"（β）——**α+β 双有者进核心档优先级最高；纯β搭车（驱动分型为周期型/非经常型且无个体订单/份额证据、只靠板块映射）不得进核心档**。
