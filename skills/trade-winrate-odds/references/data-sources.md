# 数据采集路由

原则：**只用本回合工具实际返回的数据**。工具失败/无数据 → 该维记 `null`，
不得用记忆或推测填充。每项数据记录截止时间（行情到分钟、新闻到日期）。

调用某插件/数据源前，先用 `Skill` 工具加载对应技能（`ifind`、`yahoo_finance`、
`sec_edgar` 等）获得调用方法；插件工具不可用时按 fallback 顺序降级。

## 按市场的数据源优先级

| 市场 | 行情/技术/基本面 | fallback |
|---|---|---|
| A 股 | `ifind`（同花顺） | `kimi_search_v2` 补行情摘要 |
| 港股 | `ifind` | `yahoo_finance` |
| 美股 | `yahoo_finance` | `sec_edgar`（基本面/公告）、`ifind` |

## 按维度的采集清单

### technical 技术面

- 近 300 日日 K（至少 120 日）：收盘价序列
- 用 managed Python / pandas 自算：MA5/20/60、MACD(12,26,9)、RSI(14)、
  52 周高低点、ATR(14)（止损/目标价用）
- 港股/美股可用 `yahoo_finance` 历史价格接口取数

### volume 量能

- 当日成交量/成交额 vs 近 20 日均量（量比）
- 近 5 日量能结构：放量日收阳还是收阴、回调是否缩量
- 盘中评估时注明"量能按当前时点折算，收盘后需复核"

### news 消息面

- `kimi_search_v2` 查询（按相关性+时效排序）：
  - `{股票名} 公告`、`{股票名} 业绩`、`{股票名} 最新`
  - `{股票名} 减持 OR 处罚 OR 问询`（专项排雷）
- `kimi_fetch_v2` 打开公告/新闻原文核实，区分**已证实公告**与**传闻**
- 记录每条消息的发布日期，评估是否已被股价兑现

### macro 宏观

- `kimi_search_v2`：当前货币政策（LPR/美联储利率路径）、流动性、汇率、
  重大政策与外围市场状态
- 中长期周期可补充 `imf` / `world_bank_open_data` 的宏观数据
- 只取与所选周期匹配的信息：日内交易不需要季度 GDP

### industry 行业

- 确认标的所属行业/概念板块
- `kimi_search_v2`：`{行业} 景气`、`{行业} 政策`、`{行业} 涨价/需求`
- 板块近期表现：行业指数涨跌幅、是否当前市场主线

### position 价格位置 / 估值

- 现价距 52 周高/低点的位置、近 10 日涨幅
- 估值：PE/PB 及历史分位（ifind / yahoo_finance 的基本面数据）

## 数据完整度

- 6 维全部取到 → 完整度 1.0，胜率区间最窄
- 缺 1-2 维 → 可出报告，区间加宽，报告中明示缺失维度
- 缺 3 维及以上，或**行情数据完全取不到** → 不出评分，只给数据采集结果，
  并说明"当前信息不足以做胜率评估"
