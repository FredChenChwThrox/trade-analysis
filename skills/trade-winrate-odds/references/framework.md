# 评分框架细则

打分对象为一个交易标的（+ 周期）。所有评分站在**评估时点**、面向**所选周期**。
打分本身不带方向预设：+ 分代表多头证据，− 分代表空头证据，**综合分 z 的符号
决定交易方向**。

## 目录

1. 周期与权重表
2. 六维打分锚点（-3 ~ +3）
3. 方向判定与落地约束
4. 胜率映射与区间
5. 止损价 / 目标价确定法（赔率的基础）
6. 评级与仓位
7. 认知偏差清单（打完分逐项自查）

## 1. 周期与权重表

| 维度 key | 日内 | 短线 1-5 日 | 波段 5-20 日（默认） | 中长线 1-6 月 |
|---|---|---|---|---|
| `technical` 技术面 | 0.30 | 0.28 | 0.25 | 0.15 |
| `volume` 量能 | 0.25 | 0.20 | 0.15 | 0.05 |
| `news` 消息面 | 0.20 | 0.22 | 0.20 | 0.15 |
| `macro` 宏观 | 0.05 | 0.08 | 0.15 | 0.25 |
| `industry` 行业 | 0.10 | 0.12 | 0.15 | 0.20 |
| `position` 价格位置/估值 | 0.10 | 0.10 | 0.10 | 0.20 |

脚本 `calc_ev.py` 的 `horizon` 取值：`intraday` / `short` / `swing` / `long`。
也可在输入 JSON 里传 `weights` 对象整体覆盖（六维权重之和须为 1）。

## 2. 六维打分锚点

取**最贴近的一档**，整数分，不插值。每分必须能写出一句数据证据。
+ 分 = 多头证据，− 分 = 空头证据。

### technical 技术面（趋势 + 动量 + 形态）

- +3：多头排列（价 > MA20 > MA60），放量突破关键平台/前高，MACD 零上金叉
- +2：站上 MA20 且 MA20 上行，MACD 金叉或红柱放大，无背离
- +1：站上 MA20 但均线粘合/方向不明，或动量指标刚转强
- 0：横盘震荡、多空信号混杂，或指标中性（RSI 45-55 无趋势）
- -1：跌破 MA20 或 MA20 拐头向下，动量转弱
- -2：空头排列雏形（价 < MA20 < MA60），MACD 死叉/绿柱放大，或顶背离确认
- -3：明显下降趋势 + 破位放量下杀，或利好兑现后的高位放量长阴

### volume 量能（量价配合，对照近 20 日均量）

- +3：温和放量上涨（量比 1.5-3）且回调缩量，筹码交换健康
- +2：当日明显放量收阳，量价齐升
- +1：量能略高于均量，方向与价格一致
- 0：量能平于均量，或量价信号不明
- -1：缩量上涨（跟风不足）或放量滞涨
- -2：放量收阴 / 冲高回落放大量（分歧加大）
- -3：巨量长阴 / 天量天价等典型出货量能结构

### news 消息面（已发布/已证实信息，传闻打折）

- +3：超预期业绩/重大合同/政策直接利好，且**尚未充分兑现**（发布 ≤ 3 日且涨幅 < 利好量级）
- +2：明确利好（公告、中标、获批、上调指引），市场初步反应
- +1：小幅利好或利空出尽（坏消息落地后不再创新低）
- 0：无重要消息，或多空消息对冲
- -1：小幅利空（减持预告、问询函等）
- -2：明确利空（业绩预亏、监管处罚、大客户流失）
- -3：重大利空（暴雷、退市风险、核心逻辑证伪）
- 传闻/小作文：按对应档位**降 1 档**处理，并在证据中注明"未证实"

### macro 宏观（对所选周期的方向性影响）

- +3：宽松加码（降准降息/财政刺激落地）+ 外资/增量资金持续流入
- +2：流动性边际宽松，政策暖风，风险偏好上行
- +1：宏观平稳偏暖，无压制因素
- 0：中性，或多空因素对冲
- -1：外围扰动（加息预期、汇率贬值、地缘摩擦）但未恶化
- -2：流动性收紧 / 系统性下跌进行中（指数破位）
- -3：危机模式（急剧收紧、熔断式下跌、重大黑天鹅）

### industry 行业（标的所属板块）

- +3：行业景气上行 + 政策/产业趋势双驱动，板块资金净流入居前，为当前主线
- +2：板块走强，有催化剂（涨价、技术突破、政策文件）
- +1：板块温和走强或轮动脉冲
- 0：板块跟随大盘，无独立逻辑
- -1：板块走弱或资金流出
- -2：行业景气下行 / 政策压制
- -3：行业性利空（集采、限产、颠覆性替代）

### position 价格位置 / 估值

- +3：长期处于底部区域（距 52 周高点回撤 > 40%）且估值低于历史中位，刚启动
- +2：回调到关键支撑（MA60/年线/前平台）企稳，估值合理偏低
- +1：位置中性偏低，风险释放较充分
- 0：中位震荡，估值处于历史中枢
- -1：短线涨幅较大（10 日 > 15%）但未过热
- -2：高位（距 52 周高点 < 10%）且估值高于历史 80% 分位
- -3：短期暴涨后（10 日 > 30%）或历史高位 + 估值极端泡沫区

## 3. 方向判定与落地约束

方向是评分的结果，不是输入：

| 综合分 z | 判定 | 动作 |
|---|---|---|
| z ≥ +0.6 | 多头候选 | 按多头设定止损/目标，计算 EV |
| z ≤ −0.6 | 空头候选 | 见下方市场约束 |
| 0.6 > z > −0.6 | 观望 | 多空信号混杂、无统计优势：不计算 EV，报告说明主要分歧维度 |

- **阈值对称**：多头与空头使用同一阈值 0.6（对应顺向胜率约 59% 起）
- **A 股个股**：做空基本不可行（融券受限）→ 空头候选时：
  - 持仓者：建议减仓/离场，给出离场参考位（上方阻力/反抽位）
  - 空仓者：建议观望，不给买点
  - 不计算空头 EV
- **港股/美股**：账户支持时再按空头计算（融券、认沽期权、反向 ETF 均可），
  报告中注明所假设的做空工具
- **用户自带方向**：与 z 方向冲突时（如用户想做多但 z = −1.2），报告必须
  明示"评分方向与你的方向相反"，并列出主要反向证据；不得为顺从用户而调分
- **方向反复**：|z| 在 0.6 附近（±0.15 内）时，报告中提示"方向信号偏弱，
  接近观望区"，避免给用户过强的方向感

## 4. 胜率映射与区间

- 顺信号方向：`P = 1 / (1 + e^(-0.6·|z|))`，封顶 0.72、封底 0.30
  - |z| = 0.6 → 59%；|z| = 1 → 65%；|z| = 2 → 77% → 取 72%
  - 方向对称：做多 z = +1.2 与做空 z = −1.2 的胜率相同
- 区间半宽 `= 0.05 + 0.10 × (1 − 完整度)`，完整度 = 已评分维度权重之和
  - 例：缺 2 维（合计权重 0.35）→ 半宽 ±8.5%
- 封顶是因为：公开信息下的主观评估存在模型误差与未知信息，任何维度组合都不应
  得出"接近确定"的结论。报告中不得给出超过 75% 的胜率表述

## 5. 止损价 / 目标价确定法

赔率 R 完全由三个价格决定，价格必须有依据。空头取镜像。

**多头止损**（取其一，优先技术位）：
- 关键支撑下方 1-2%：前低、缺口下沿、MA20/MA60、平台下沿
- ATR 法：`入场价 − 2 × ATR(14)`，波动大的票用 2.5 倍
- 逻辑止损：入场逻辑被证伪的价格（如突破买入则跌回平台内即止损）

**多头目标**（取其一，保守者优先）：
- 上方最近压力位：前高、筹码密集区、整数关口
- 测量涨幅：突破形态的等幅测量（如头肩底颈线上翻）

**空头止损**：上方阻力上方 1-2%（前高、平台上沿），或 `入场价 + 2 × ATR(14)`

**空头目标**：下方最近支撑位（前低、缺口、MA60），或下跌形态的等幅测量

**通用约束**：
- 若最近压力/支撑位算出的 R < 1.5，应在报告中说明"赔率不佳"，
  不得为提高 R 而人为拉远目标价
- **入场即定损**：没有止损价的交易不计算 EV，直接提示"先定义退出点"

## 6. 评级与仓位

| 评级 | 条件 | 含义 |
|---|---|---|
| A | EV ≥ 0.30 且 P ≥ 0.60 且完整度 = 1 | 高质量机会 |
| B | EV ≥ 0.15 | 可做，控制仓位 |
| C | EV > 0 | 边际机会，小仓或观望 |
| D | EV ≤ 0 | 放弃 |

仓位参考 = `Kelly/4 = (P − (1−P)/R) / 4`，clamp 到 [0, 25%]。这只是数学参考，
报告中须提示结合自身风险预算。评级与仓位规则对多空两个方向同样适用。

## 7. 认知偏差清单（打完分逐项自查）

1. **近因偏差**：三连阳/三连阴不等于趋势，动量分需要均线/结构证据支撑
2. **确认偏误**：为每个 ≥ +2 或 ≤ -2 的分，强制写一条反方证据放入风险段
3. **利好/利空兑现**：重大消息发布已久且股价已大幅反应 → 消息面与位置分要联动下修
4. **锚定成本**：用户持仓成本与评分无关；评分只面向未来周期
5. **大盘连坐**：指数 -2 档时，个股 z ≥ +1.5 才可给多头 B 以上评级；
   对称地，指数 +2 档时，个股 z ≤ -1.5 才可给空头 B 以上评级
6. **幸存者叙事**：不因"热门股/大 V 推荐"加任何分，只认可验证数据
7. **方向执念**：不因用户表达过方向倾向而倾斜打分；分数只对应数据证据
