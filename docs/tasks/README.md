# UI 第一期任务总览

## 目标

为股票分析系统构建一个基于数据库的只读 Web UI，支持股票筛选、单股/多股指标时间序列展示、信号时间轴、卡片版本和运行状态查看。

## 技术栈

- 后端：Flask + 原生 SQLite
- 前端：原生 HTML + Tailwind CSS CDN + ECharts CDN
- 配置：`config/ui.yaml`

## 执行建议

1. 单人执行：按序号从 00 到 11 顺序执行。
2. 多人并行：
   - 路径 A：00 -> 01 -> 02 -> 03 -> 04 -> 10
   - 路径 B：01 -> 05 / 06 / 07 / 08 / 09（待 02 完成后可独立推进前端）
   - 最后统一 11
3. 最小可用版本（MVP）：00 -> 01 -> 02 -> 03 -> 04。完成后即可满足"查看每个指标按时间变化"的核心需求。

## 关键约束

- 所有 API 只读，不提供写入接口。
- 不固定任何股票 symbol；所有数据来自数据库或用户输入。
- 价格展示必须支持复权/不复权切换，并明确标注。
- 多股/多指标查询限制数量，防止性能问题。
- 所有筛选条件应同步到 URL，便于刷新和分享。
