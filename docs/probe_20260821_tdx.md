# 数据源实测记录：通达信 tdx-connector（2026-08-21）

> 背景：kimi-datasource 插件 access_token 失效（`access_token was rejected. Run /login again`），
> 且 stock_finance_data 公告接口自 2026-08-13 持续 EMPTY_DATA、指数接口长期 EMPTY_DATA。
> 改接入通达信 MCP 作为第一优先数据源。原始试采文件：`data/raw/tdx/{kline,index,announcement,quotes}/2026-08-21/run_probe_tdx/`

## 接口清单

| 工具 | 用途 | 关键参数 |
|---|---|---|
| `tdx_kline` | K 线历史序列（A 股/港股/指数/期货） | code（纯数字）+ setcode + period=4（日线）+ tqFlag（0不复权/1前/2后）+ wantNum |
| `tdx_quotes` | 实时行情快照 + 估值指标 | code + setcode + hasCwInfo=1（含 PE/PB/ROE/总市值/股东人数） |
| `wenda_notice_query` | 公司公告 | name（公司全称）+ symbol + bdate/edate（YYYYMMDD） |
| `tdx_api_data` | 统一 API（港股财报/股本结构/十大股东等） | entry + code + fixedTag（港股损益 fixedTag=1/资负=2/现金流=3） |
| `wenda_report_query` | 券商研报 | code + keyword + date_range |
| `wenda_news_query` | 新闻资讯 | keyword + category |
| `wenda_macro_query` | 宏观数据 | indicator（CPI/社融/PMI） |

> setcode 对照：1=沪A 0=深A 2=北交所 31=港股 62=中证指数 32=港股指数

## 字段映射

### tdx_kline → daily_bars / index_bars

返回 `Rows[]` 数组，每根 K 线含：Data（YYYYMMDD）、Open/High/Low/Close、Volume、Amount、RawVolume、Unit。

| tdx 字段 | 系统字段 | 说明 |
|---|---|---|
| Data | trade_date | 20260821 → 2026-08-21 |
| Open/High/Low/Close | open_raw/high_raw/low_raw/close_raw | 不复权价（tqFlag=0） |
| Volume | volume_raw | **单位手（Unit=100），adapter ×100 转股** |
| Amount | amount_raw | 单位元，kimi 缺此字段，tdx 是优势 |
| AttachInfo.Name | 不入库 | 港股 00700 返回"模塑科技"是已知名字错（数据正确） |
| setcode | symbol 后缀推断 | 1→SH 0→SZ 2→BJ 31→HK 62→SH（指数） |

### tdx_quotes hasCwInfo=1 → share_capital_events

返回 ExtInfo + CwInfo，含估值/股本/财务指标。

| tdx 字段 | 系统字段 | 说明 |
|---|---|---|
| ExtInfo.SYL | details.pe | 市盈率 |
| ExtInfo.MGJZC / Close | details.pb | PB = Close / MGJZC |
| ExtInfo.ZGB | shares_issued_after | 总股本（万股，×10000 转股） |
| ExtInfo.ZSZ | details.zsz | 总市值（元） |
| CwInfo.GDRS | details.gdrs | **股东人数（系统长期缺的筹码集中度指标，§5.7）** |
| CwInfo.JLY | details.jly_wan | 净利润（万元） |
| CwInfo.YYSR | details.yysr_wan | 营业收入（万元） |
| CwInfo.JYXJL | details.jyxjl_wan | 经营现金流（万元） |

> 写 share_capital_events（event_type=snapshot_group_total_tdx，share_count_type=group_total_tdx），
> **不参与 valuation.py PE 取数**（仅认 issued/group_total），作为 tdx 估值备查快照。

### wenda_notice_query → events/event_symbols

返回 `data[]` 数组，每条公告含：标题、时间、链接、来源、摘要。

| tdx 字段 | 系统字段 | 说明 |
|---|---|---|
| 标题 | events.title | |
| 时间 | events.published_at | YYYY-MM-DD HH:MM:SS，取前 10 位日期 |
| 链接 | events.canonical_url | PDF 原文链接 |
| 来源 | events.summary | "上交所"/"深交所" |
| 摘要 | 不入库 | 太长，可选 |

> 通达信公告无 uuid，按 `title|pub_date` 哈希去重（§3.6）。available_at 取下一个开市交易日 00:00 本地（§2.1）。

## 实测发现

### 1. kimi-datasource 插件鉴权失效

`call_data_source_tool` 调 stock_finance_data 任何接口均返回 `Kimi Code access_token was rejected. Run /login again and retry.`。短期修复：用户跑 `/login` 重新鉴权。专用工具名（如 `stock_finance_data_get_stock_announcement`）已废弃，全部收拢到 `call_data_source_tool` 派发器。

### 2. volume 单位换算（关键）

tdx `Rows.Volume` 单位是**手**（Unit=100），系统 `volume_raw` 口径是**股**（与 kimi 一致）。
- 603605.SH 08-17：tdx Vol=50372.18 手 × 100 = 5037218 股 ≈ kimi 5037200 股（浮点精度差异 18 股，0.0004%）
- adapter 按 CSV 的 `unit` 列换算：`volume_raw = volume × unit`（unit=100 手→股，unit=1 指数原值）

### 3. amount 字段优势

kimi 行情 CSV 无 amount 列（`amount_raw = NULL`），tdx `Rows.Amount` 单位元直接可用。08-17 tdx amount=284190240 元入库，触发 `data_revisions` 记录（source_revision），补全 kimi 历史缺口。

### 4. 港股 K 线 Name 字段错

00700.HK 探测返回 `AttachInfo.Name="模塑科技"`（应为"腾讯"），但 OHLCV 数据正确（价格 10.75 港币符合腾讯股价）。adapter 不依赖 Name 字段，不影响入库。这是通达信的已知数据瑕疵。

### 5. 指数 setcode=62 可用

沪深300（000300，setcode=62）实测 OK，弥补 kimi/yahoo 长期指数缺口（kimi `get_price` 000300.SH 持续 EMPTY_DATA；yahoo 000300.SS 8/14 发现数据空洞 07-20..08-07）。tdx 08-19/20/21 三根指数 K 线入库 index_bars。

### 6. 公告跨源去重限制

tdx 公告无 uuid，按 `title|pub_date` 哈希去重。与 tianyancha 公告（有 uuid）跨源不去重——同标题同日期公告会被视为不同事件（source_external_id/content_hash 不同）。603605.SH 现有 180 条 tianyancha 公告 + 2 条 tdx 公告（部分内容可能重复）。后续可加 `canonical_url` 跨源去重。

### 7. 股东人数 GDRS 可得

tdx_quotes `CwInfo.GDRS` 提供股东人数（603605.SH = 73274），是系统长期缺的筹码集中度间接指标（§5.7）。作为 tdx 估值快照的 details_json 字段保存，供后续 LLM 评价或人工参考。

## 已知限制（二期）

- **港股财报**：`tdx_api_data` 港股损益/资负/现金流（fixedTag=1/2/3）能力存在但 adapter 未实现 parse_financials_csv，二期补。
- **资金/筹码分布**（盘口夹板/托单）：数据源不可得，§3.6 评估为无源。
- **港股日历**：仍需 `config/calendar_HK_{year}.yaml` 种子文件，tdx 不提供交易日历。
- **跨源公告去重**：tdx 与 tianyancha 同标题公告不去重，后续加 canonical_url 跨源去重。
